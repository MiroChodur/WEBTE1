## 🌐 O projekte
Tento web funguje ako osobná študentská vizitka rozdelená do 5 responzívnych podstránok. Obsahuje profil, životopis, interaktívne pracovné prostredie, dynamický rozvrh hodín s indikátorom prebiehajúcej výučby a mapu s výpočtom vzdialeností.
